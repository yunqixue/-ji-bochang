# 数据文件登记表

> **大文件不放仓库。** 数据集、模型权重、录屏一律放共享云盘 / NAS，在这里登记一行。
> 谁需要谁按「位置」自己取。取不到就 @ 负责人。

## 共享位置

| 类型 | 位置 | 说明 |
|---|---|---|
| 共享云盘 | 待填（如 阿里云盘 / OneDrive / 坚果云 共享文件夹链接） | 大文件统一放这里 |
| 内网共享 | 待填（如 `\\192.168.x.x\team-data`） | 需要同一局域网 |
| 数据集原始出处 | 待填（官方下载链接） | 能下载就别传，写明链接和版本 |

## 登记规则

1. 只写**能直接定位**的位置，不要写「问我要」
2. 文件名带版本号，别覆盖旧文件（`v1`、`v2`），覆盖了别人跑的实验就复现不了
3. 数据集要写明出处和许可证，避免答辩时被问住
4. 需要校验的加一行文件大小，方便判断是否传完整
