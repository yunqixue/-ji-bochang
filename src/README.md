# src · 源码目录

按层分包，一人一层，减少冲突。

| 目录 | 层 | 负责人 | 说明 |
|---|---|---|---|
| `perception/` | 感知层 | 成员A | 语音/表情/文本情绪识别，输出 `PerceptionResult` |
| `cognition/` | 认知层 | 成员B | 对话策略、情绪记忆、LLM 编排，输出 `CognitionResponse` |
| `presentation/` | 表现层 | 成员C | TTS、表情动作驱动、前端界面 |
| `shared/` | 共用 | 三人共担 | 数据结构定义、配置、日志、评测工具 |

**铁律：**

1. 三层只通过 `docs/接口契约.md` 里定义的两个结构通信，不互相 import 内部函数
2. 数据结构定义放 `shared/`，改字段先改契约文档
3. 每层先写 mock（返回契约里的固定样例），端到端联调就能提前跑起来
4. 自己的目录自己清理，不往别人目录里放文件

建议起步顺序：先由一人把 `shared/` 里的数据结构 + 两个 mock 落地提交，另外两人拉下来就能并行开发。
