# 3D 形象模型（xiaoyu.glb）获取方法

3D 引擎（TalkingHead + Three.js）已经装好并在页面里接好了，**只差一个模型文件**。
把这个文件放到本目录，刷新页面即自动启用 3D；不放则页面保持原来的 2D 立绘，什么都不影响。

## 目标文件

```
src/presentation/static/avatar/xiaoyu.glb
```

要求：Ready Player Me 全身模型，**必须带 ARKit + Oculus Visemes 变形目标**（否则脸不会动）。

## 方法一：自己捏一个（推荐，可以照着"小雨"的 2D 立绘捏）

1. 浏览器打开 https://readyplayer.me （支持微信扫码/邮箱注册，免费）
2. 选"全身"（Full Body），按喜好捏脸、发型、衣服
3. 完成后复制头像链接，形如：
   `https://models.readyplayer.me/xxxxxxxxxxxxxxxx.glb`
4. **在链接末尾加上参数**（这步最关键，不加就没有表情变形数据）：
   ```
   https://models.readyplayer.me/xxxxxxxxxxxxxxxx.glb?morphTargets=ARKit,Oculus%20Visemes
   ```
5. 把这个完整链接粘贴到浏览器地址栏下载，得到的文件重命名为 `xiaoyu.glb`，放进本目录

## 方法二：先用官方示例模型跑通（2 分钟）

在浏览器里直接下载下面任一个（已带好变形参数）：

```
https://models.readyplayer.me/64bfa15f0e72c63d7c3934a6.glb?morphTargets=ARKit,Oculus%20Visemes
https://models.readyplayer.me/664956c743dbd726eefeb99b.glb?morphTargets=ARKit,Oculus%20Visemes
```

下载后重命名为 `xiaoyu.glb` 放进本目录即可。

## 验证

启动服务后打开页面，看浏览器控制台（F12）：
- `[avatar3d] 3D 形象已就绪` → 成功
- `未找到 3D 模型` → 文件路径/名字不对
- 其他报错 → 模型缺 morphTargets（回第 4 步检查 URL 参数）

> 提示：models.readyplayer.me 在某些网络下需要代理才能打开。如果直连失败，
> 用手机流量开热点试试，或让能上的同学帮忙下一个。
