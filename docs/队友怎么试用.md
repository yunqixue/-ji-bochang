# 给队友（A 张敬伟 / C 梁苇）：怎么和这个智能体聊天

> A 是产品负责人，「够不够暖」由他判断；C 负责前端和工程落地。
> 这份只说**怎么进来聊**、**怎么配 Key（不配就是人机）**、**聊完怎么把结论交回来**。
> 最后更新：2026-10-24（B）

---

## 零、先说清楚：没有 Key 的回复不能用来验收

这个智能体的「人设」全部来自大模型。**没有 Key 的时候，它退化成固定模板**——
就是"哦这样啊。那你现在打算怎么办？"这种，一听就是机器。拿那种状态验收，
结论一定是"太人机了"，但那不是产品的问题，是没接上模型。

所以**验收前必须先有 Key**。三种拿法，任选一种：

| 拿法 | 你要做什么 | 成本 |
|---|---|---|
| **A. 直接用 B 开的链接**（最省事） | 什么都不用做 | B 出（几十轮对话也不到一块钱） |
| **B. 让 B 给你单独开一个 Key** | B 在 DeepSeek 后台新建一个 Key 发你，你粘进 `api_key.txt` | B 出，用完 B 删掉（可随时撤销，也能看用量） |
| **C. 自己注册一个** | 去 platform.deepseek.com 注册，建 Key（新用户通常有免费额度，以官网为准） | 自己出，验收这点量几乎可以忽略 |

> 为什么推荐 B 而不是"把 B 的 Key 借来用"：**每人一个 Key** 是团队约定（`AGENTS.md` 第 6 节）。
> 单独开一个能随时撤销，出了事不影响别人；直接传同一个 Key，等于谁都撤不掉。

### 配好之后怎么一键验证（不用猜）

**双击项目根目录的 `配置Key.cmd`**：

1. 它会打开 DeepSeek 的 API keys 页面，你新建一个、复制那串 `sk-…`
2. 然后弹出记事本，把 Key 整串粘进去（文件里只放这一串，不带引号、不留别的行）
3. 保存并关掉记事本，它会**真的调一次模型**，直接告诉你结果

它给出的结论只有这几种，各自对应不同的处理：

| 提示 | 意思 | 怎么办 |
|---|---|---|
| ✅ 调用成功 | Key 能用 | 双击 `run.cmd` 开始聊 |
| ❌ Key 无效或已被删除 | 粘错、粘一半、或者 Key 被删了 | 重新建一个，注意别多带空格 |
| ❌ 账户余额/额度不够 | Key 有效但没钱了 | 充值，或改用 B 的链接 |
| ❌ 连不上 api.deepseek.com | 网络/代理问题，**不是 Key 问题** | 换网络；公司网常见 |
| ⚠️ 不是以 sk- 开头 | 多半粘错了东西 | 重新复制 |

**改完 Key 必须重启服务**（关掉服务窗口再双击 `run.cmd`），否则还在用旧的。

**最终确认**：浏览器打开 `http://127.0.0.1:8000/api/health`，
看到 `"llm": true` 就是接上了；`false` 说明还在模板状态，别急着评价。

## 一、三条路，按你想花的时间选

| 方案 | 谁操作 | 要多久 | 能不能用麦克风说话 |
|---|---|---|---|
| **① 用 B 开的临时链接**（最快） | B 开，你点链接 | 2 分钟 | ✅ 能（https 链接可以录音） |
| **② 在你自己的电脑上跑**（最稳） | 你自己 | 15–30 分钟 | 文字 ✅；语音要额外装东西 |
| **③ 同一个局域网直连** | B 开，你访问 IP | 2 分钟 | ❌ 只能打字（浏览器不给 http 页面麦克风） |

### 方案① 用 B 的临时链接（推荐先这样）

1. 让 B 在他电脑上双击 **`start-demo.cmd`**
   （第一次会先下载 50MB 的 cloudflared，可能需要几分钟；**别等到要用的时候才第一次跑**）
2. B 的窗口里会打印一个 `https://xxxx.trycloudflare.com` 链接，并自动复制到剪贴板
3. B 把这个链接发给你，**你用浏览器直接打开就行，什么都不用装**
4. 点「按住说话」允许麦克风，就可以真的说话了

注意事项（照做，不然会踩坑）：

- **链接是临时的**：B 一关窗口就失效；每次重开都是一个新的随机地址，不要收藏
- 你每说一句都在用 B 的 DeepSeek 额度，测完就停，别挂在那儿刷
- 如果链接打不开，先问 B 窗口还开着没有

### 方案② 在你自己的电脑上跑（建议认真验收用这个）

前提：装过 Git、Python 3.10 或更高。检查一句 `python --version` 看版本。

```powershell
# 1. 拿到代码（第一次）—— 之后每天开工双击 pull.cmd 就行
git clone https://gitee.com/QLZ147258/ji-bochang.git

# 2. 装依赖（国内用清华源快很多）
python -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple fastapi "uvicorn[standard]" python-multipart openai edge-tts

# 3. 配 Key：双击 配置Key.cmd（会自动打开页面 + 记事本 + 验证，见第零节）
#    ★ 必须做，否则回复是固定模板，验收结论无效

# 4. 双击 自检.cmd —— 看缺什么。全是绿色就可以往下走
# 5. 双击 run.cmd，浏览器打开 http://127.0.0.1:8000
```

**C 的机器特别说明**（Python 3.14）：`uvicorn[standard]` 装不上，改成不带方括号的：

```powershell
python -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple fastapi uvicorn python-multipart openai edge-tts
```

这样**文字对话 + 语音输出都能用**，只有「语音输入」用不了（faster-whisper 没有 3.14 的安装包）。
验收人设完全够用；语音输入在 B 的机器上验。

**语音输入（可选）**：文字对话已经够验收人设了。想要真说话，再装这两步：

```powershell
python -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple faster-whisper
python experiments/download_asr_model.py      # 下模型，约 150MB，两分钟
```

> 装不上也别耽误时间 —— B 的机器（Python 3.10）上语音链路是通的，演示跑他那台。

## 二、重点：别"随便试试"，带着任务聊

现在的状态是：代码能跑、但你欠的那份「真实对话标注 + 问题清单」还是空的（任务板交接点 #7）。
你聊的时候顺手就能把它填掉。**按下面 8 条走一遍，大概 20 分钟：**

| # | 你说什么 | 你要判断什么 |
|---|---|---|
| 1 | 照 `docs/演示脚本.txt` 的**演示 1** 三句连着说 | 有没有被"接住"？第 2、3 句她记得前面说的吗？ |
| 2 | 同上的**演示 2** 三句 | 表情/语气有没有跟着变？ |
| 3 | 同上的**演示 3** 三句（第 2 句是"上次说的那个面试"） | 她有没有分清"是接着前面那件事"，而不是当新事件 |
| 4 | **同一句话连说两遍**（比如"我今天面试没过"发两次） | 会不会一字不差地回同一句（刚修过，重点验） |
| 5 | 「你是不是 AI」「你几岁了」 | 有没有坦白，装小孩还是诚实 |
| 6 | 「我想让你分享一些你觉得好玩的经历」 | 是讲了一段具体的事，还是一句话概括完就反问（后者像敷衍） |
| 7 | 说一句**很长的、乱的**倾诉（三四行那种） | 她抓的是重点还是回得很空 |
| 8 | 说一句**完全中性**的话（"今天天气不错"） | 会不会硬往情绪上扯、会不会说教 |

**每一条都记两件事**：① 她的回复原文；② 你作为产品负责人的判断——够不够暖、像不像人、有没有客服腔。

填在这两个文件里：

- `assets/samples/对话标注表_30条_实测.csv`
  —— 已经有 30 条输入和实际回复了，你只需要填 **`像不像人1-5`、`客服腔`、`说教`** 这三列
- `assets/samples/问题清单.md`
  —— 现在还是空模板，按严重度写你发现的问题，一条一行

## 三、你需要知道的三个"已知问题"（别当成 bug 报）

1. **偶尔某一句没声音**：语音是现场联网合成的，网络一抖那一句就没声，下一句又正常。
   想知道具体原因，浏览器打开 `http://127.0.0.1:8000/api/health`，看 `tts_last_error`。
2. **说话时嘴不动**：现在没有"张嘴图"（`assets/images/expr_*_talk.webp`）。
   **A 出 1 张就自动生效**，前端不用改 —— 这是目前性价比最高的一步。
3. **声音不对（比如觉得像男生）**：先看 `/api/health` 里的 `tts_last_backend`：
   - `edge` = 在线音色（正常的那一个，实测基频 283 Hz，是女声/女童区间）
   - `sapi` = 退到了本机离线语音，音色**完全不同**，而且很多机器上会是个男声在硬读中文
   觉得现有音色不好听（而不是"像男生"），去 `experiments/voicetest/index.html` 双击试听 9 个备选音色，
   告诉 B 你要哪个编号即可。

## 四、聊完怎么把结论给 B

微信里说一句「我试完了，问题清单在仓库里」即可，B 下次开工就会看到。
如果问题很严重（比如"感觉像机器人"），直接说，别写文档，先让 B 改。

**别自己改代码和人设文本** —— 人设和话术是你的，但改法要过 B 的手（他把话术接进提示词、跑回归测试）。
