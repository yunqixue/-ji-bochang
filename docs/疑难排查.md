# 疑难排查（一般不用看，卡住了再来）

> 这份是给"照着 使用方法.txt 做但卡住了"的情况。
> 命令都在 **PowerShell 黑窗口**里执行：按 `Win` 键 → 输入 `powershell` → 回车。

---

## 1. 提示 `git 不是内部或外部命令`

**原因 1（最常见）：装完 Git 没重开窗口。** 把黑窗口全关掉，重新打开一个。

**原因 2：PATH 指错了。** 真实案例：Git 装在 `D:\claudecode\Git`，
但系统 PATH 里写的是 `D:\claude code\Git\cmd`（**多了一个空格**），所以永远找不到。

诊断（看哪条路径是假的）：

```powershell
($env:Path -split ';') | Where-Object { $_ -match 'Git' } | ForEach-Object {
    "{0}  ->  {1}" -f $_, (Test-Path $_)
}
```

输出里 `False` 那条就是坏路径。

修法（不需要管理员，推荐）：把真实路径追加到用户 PATH

```powershell
$correct = "D:\claudecode\Git\cmd"    # 换成你自己 git.exe 所在目录
$userPath = [Environment]::GetEnvironmentVariable('Path','User')
if ($userPath -notlike "*$correct*") {
    [Environment]::SetEnvironmentVariable('Path', "$userPath;$correct", 'User')
    "已追加，重开窗口生效"
}
```

修法 B（需管理员）：`系统属性 → 环境变量 → 系统变量 Path`，把坏的那条改成正确的。

> 注意：**项目的 push.cmd / pull.cmd 不用管 PATH 也能跑**，它们会自动去常见目录找 `git.exe`。
> PATH 只影响你手动敲 `git` 命令。

## 2. 提示「禁止运行脚本」/ `running scripts is disabled`

本项目的两个按钮已经带了绕过参数（`-ExecutionPolicy Bypass`），正常不会碰到。
万一手动执行脚本被拦：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\sync.ps1 -PullOnly
```

---

## 3. 提示 `Author identity unknown`

没设提交身份。执行一次（换成你自己的）：

```powershell
git config --global user.name "你的真名"
git config --global user.email "你的邮箱"
```

三人各设各的，提交记录里就能分清谁改了什么。

---

## 4. 提示 `Authentication failed` / `403`

密码填错。Gitee 的 HTTPS 推送**不能用登录密码**，要用**私人令牌**：

Gitee → 头像 → 设置 → 安全设置 → 私人令牌 → 生成新令牌 → 权限勾 `projects` → 生成 → 复制。

⚠️ 令牌只显示一次，先存记事本。

---

## 5. 提示 `Repository not found` / `not found`

两种情况：

1. 你还没被加进这个仓库（让队长在 Gitee → 管理 → 仓库成员管理里邀请你，**你还要去消息里点接受**）
2. 仓库地址写错了

---

## 6. 提示 `schannel` / `SEC_E_NO_CREDENTIALS` / `基础连接已关闭`

这台电脑的 HTTPS 加密组件有问题（本机真实遇到过）。让 git 换用 OpenSSL：

```powershell
D:\claudecode\Git\cmd\git.exe config http.sslBackend openssl
```

路径换成你自己的 `git.exe` 位置。然后重新双击 `push.cmd`。

---

## 7. push 提示「别人先上传了」/ `rejected`

别人比你早推。**先双击 `pull.cmd`，再双击 `push.cmd`。**

---

## 8. 提示冲突 / `conflict` / `CONFLICT`

**停手，不要自己乱改乱删。** 把整个窗口截图发群里。
手动处理冲突很容易把队友的代码删掉，这不是自己能试出来的。

## 9. 队友的 AI 好像不知道项目背景

1. DSH 的工作区（workspace）是不是指向了 `情感交互智能体Agent开发` 这个文件夹？
2. 这个文件夹里有没有 `AGENTS.md`？
3. 是不是很久没 `pull` 了，本地文件是旧的？

验证方法：开新会话说「我们这个项目的分工是什么？我负责哪部分？」
能答出 A/B/C 就说明加载成功。

## 10. 千万别做的三件事

| 别做 | 后果 |
|---|---|
| 删 `.git` 文件夹 | 同步关系全断，历史全没，只能重新 clone |
| 把数据集/模型/录屏提交进仓库 | 仓库瞬间变几个 G，队友每次 pull 都要等很久 |
| 直接改别人负责的目录 | 冲突和代码被覆盖，最难排查的那种问题 |
