> **冻结原则：三天内不许换技术栈。** 真要换，必须在文末「变更记录」写一行并让三人知晓。

## 选型表

| 环节 | 选定方案 | 为什么选它 | 备选（仅在选定方案失败时启用） |
|---|---|---|---|
| 前端 | **单页 HTML + 原生 JS**（MediaRecorder + Audio） | 无构建步骤，改完刷新就能看 | 不要上 Vue/React，构建配置会吃掉半天 |
| 后端 | **Python 3.10 + FastAPI + uvicorn** | B 和 C 都能写，自带 `/docs` 调试页 | Flask（没必要） |
| 语音识别 ASR | **faster-whisper**（本地 CPU，`small` 模型） | 离线、免费、**演示现场断网也不怕**；用自带 `av` 解码 webm，**不用装 ffmpeg** | 阿里云 / 讯飞实时语音 API |
| 语音合成 TTS | **edge-tts**（微软，免费） | 一行代码出语音，中文音色好，支持 `rate` / `pitch` —— 正好映射契约的 `speech_rate` / `pitch_shift` | pyttsx3（离线 SAPI，音色差但能兜底） |
| 大模型 | **DeepSeek API**（用 openai SDK 调用） | 已有 Key，中文表现好 | — |
| 情绪识别 | **由 LLM 一次调用同时输出情绪标签 + 回复**（返回 JSON） | 零训练、零额外依赖，三天内唯一可行路径 | librosa 提取能量/音高辅助判断 arousal |
| 多轮记忆 | **进程内 `dict[session_id]`**：最近 8 轮原文 + 1 段滚动摘要 | 不碰数据库，重启就丢，演示够用 | sqlite（时间允许再说） |
| **形象** | **静态立绘 7 张（webp）+ 按情绪换图 + CSS 微动效** | 2–4 小时完成，效果稳定可控；不用学 Live2D，也没有授权风险 | 短视频循环（有余力再升级） |
| 部署 / 演示 | 本机 `uvicorn` 起服务，内网穿透给外人访问 | 演示只要能打开就行 | 云服务器 |

## 形象方案细节（C 照此实现）

**素材**：`assets/images/expr_*.webp`，7 张同一个人（生成方法见 `assets/prompts/形象生成提示词.md`）。

**状态机**（前端）：

| 状态 | 触发 | 表现 |
|---|---|---|
| `idle` | 等待用户 | 呼吸动效：`scale(1.00 → 1.012)`，4s 循环 |
| `listening` | 用户按下录音 | 轻微放大 + 边缘泛光（示意在听） |
| `thinking` | 已上传、等后端返回 | 显示"…"，形象保持当前表情 |
| `speaking` | 播放 TTS 音频 | `translateY(0 → -3px)` 轻微起伏，0.35s 交替；**音频结束回到 idle** |

**表情切换**：
- 用户情绪 → 换图用 `perception.emotion_label`
- 智能体回复 → 换图用 `response.target_emotion`（值 `empathic` 时用 `expr_empathic.webp`）
- 从 `speaking` 开始那一刻切到 `target_emotion` 对应的图

**换图要用交叉淡入**（两张图叠加，`opacity` 过渡 200ms），直接换 `src` 会闪。

**铁律**：图片加载失败时**必须**回落到一张纯色占位块 + 文字说明，不能让整个界面白屏。

## 风险与兜底（现在就要准备好，别等现场出事）

| 风险 | 兜底动作 | 负责人 |
|---|---|---|
| 7 张图生成了 7 个不同的人 | 用参考图/固定种子重生成；降级到 3 张 | A |
| `neutral` 出图太晚，C 没法开工 | **D1 晚上必须交出 neutral**，C 先用色块占位 | A |
| 形象加载慢 | webp 压到 300KB 以内，前端预加载全部 7 张 | C |
| faster-whisper 模型下载慢 / 失败 | 提前下好放 `data\models\`，演示机先跑通一次 | B |
| 现场没网 / LLM 超时 | 前端保留文字输入框；预置 3 条兜底话术；**准备录屏** | C |
| edge-tts 连不上 | **实测必读**：本机 10 次合成失败 2 次（连不上 `speech.platform.bing.com`）；而本机**没有中文离线语音包**，pyttsx3 和 Windows SAPI 都不可用。应对：① 实时对话 3 次重试 ② **演示前跑 `python -m experiments.prewarm_demo` 预生成缓存**（命中缓存 0.003s、不碰网络） ③ 实在没有音频时前端只显示文字 | B |
| 演示时 LLM 突然"变傻" | 已修：多轮记忆曾让模型模仿纯文本、不再输出 JSON，导致第 2 轮起悄悄降级成 mock。现已改为历史放进 system 并显式禁止模仿，同时 `debug.llm_error` 会记录降级原因 | B |
| 浏览器麦克风权限被拒 | 演示前在同一浏览器授权一次；备用 Edge | C |
| 录音格式不兼容 | 前端固定 webm/opus，后端统一用 av 解码 | C |
| 三天延期 | 优先级：文字对话 > 语音输出 > 形象 > 语音输入 > 多轮记忆 | 三人 |
