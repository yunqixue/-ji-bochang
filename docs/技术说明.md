## 一、架构：四层，前端只有一个文件

```
┌──────────────────────────────────────────────────────────────┐
│ 浏览器                                                       │
│  src/presentation/static/index.html  ← 单文件静态页（无构建）  │
│    · 录音（MediaRecorder）  · 消息气泡  · 表情/口型切换         │
│    · Q 版小人浮层（可拖动 / 摸头 / 挥手 / 跟着情绪变脸）        │
└───────────────────────────┬──────────────────────────────────┘
                            │ HTTP  (multipart: session_id + audio|text)
┌───────────────────────────▼──────────────────────────────────┐
│ app.py  · FastAPI + uvicorn（单进程，端口 8000 / 兜底 8001）    │
└───────┬───────────────┬───────────────┬──────────────────────┘
        │               │               │
   ┌────▼─────┐   ┌─────▼──────┐   ┌────▼──────────┐
   │ 感知层    │   │ 认知层      │   │ 表现层         │
   │perception│   │ cognition  │   │ presentation  │
   │          │   │            │   │               │
   │ASR       │   │情绪判断     │   │TTS（edge-tts） │
   │faster-   │   │人设对话     │   │+ SAPI 兜底     │
   │whisper   │   │多轮记忆     │   │+ 逐字时间戳    │
   │base 本地 │   │防复读       │   │静态页 / 素材    │
   │          │   │红线兜底     │   │               │
   └──────────┘   └────────────┘   └───────────────┘
                          │
                  ┌───────▼────────────────┐
                  │ src/shared/contracts.py │  ← 数据结构的唯一事实来源
                  └────────────────────────┘
```

**为什么前端只有一个文件**：三天冲刺，引入构建工具就等于引入「装不上 / 版本不一致 / 队友跑不起来」。
代价是 `index.html` 现在 3100 行，三个人改同一个文件必须先在任务板登记（真撞过两次车，见 `docs/疑难排查.md` 第 12 节）。

## 二、一次对话的数据流

```
用户说话
  │  ① 录音（MediaRecorder，webm）POST /api/chat
  ▼
app.py
  │  ② 感知层：faster-whisper(base, 本地 CPU) → 文字 + 置信度
  ▼
认知层（一次 LLM 调用，同时要情绪和回复）
  │  ③ 情绪：emotion_label / score / valence / arousal（效价-唤醒交给模型直接判，不做后端映射表）
  │  ④ 记忆：按 session_id 维护最近 8 轮 + 前文摘要；指代（"他""那件事"）靠摘要解析
  │  ⑤ 人设：A 的人设卡 + 说话规则；长度按"他要什么"分档
  │  ⑥ 防复读：与上一轮输入比相似度，重复则换说法；连续追问会主动收敛
  │  ⑦ 红线：命中自伤/极端情绪 → 直接走固定危机话术（含 12356），不让模型自由发挥
  ▼
表现层
  │  ⑧ TTS：edge-tts（晓伊），音高基线 +20Hz、语速/音高随情绪微调
  │      · 失败重试 3 次 → SAPI 离线兜底 → 复用同文缓存
  │      · 缓存键 = md5(文本 + 语速 + 音高)，命中直接返回
  │  ⑨ 口型：tts.timings_for() → words / wtimes / wdurations
  │      · edge-tts 给 WordBoundary 时是准的（estimated=false）
  │      · 命中老缓存拿不到逐字信息时，按字数均分造近似值（estimated=true）
  ▼
JSON 返回：perception / response(reply_text, target_emotion, speech_rate, pitch_shift, debug)
          / audio_url / avatar / lipsync / latency_ms
  ▼
前端
  │  ⑩ 播 mp3；表情在 expr_<情绪>.webp ↔ expr_<情绪>_talk.webp 之间 115ms 交替 = 伪口型
  │  ⑪ 右下角小人同样换表情 + 张嘴；音量分析器的读数驱动"随声音推近"和波形
  ▼
用户听到回答、看到角色变表情
```

**实测**：正常模式 3.1–4.7 秒/句（模型 2–4 秒是大头）；兜底模式 0.2–0.5 秒/句。

## 三、六个关键选择，各自付了什么代价

### 1. ASR 用本地 faster-whisper，不出网

- **换来**：断网也能语音输入；用户录音不出本机（情感陪伴场景里这是伦理上的加分项）；不按调用计费。
- **代价**：模型 150MB 要单独下（`experiments/download_asr_model.py`）；首句慢 1–2 秒；**依赖装在项目外的 `..\.pylibs`，手动启动必须设 `PYTHONPATH`** —— 不设的话服务能跑、话能说，只有麦克风静默失效（踩过，见 `docs/疑难排查.md` 第 17 节）。

### 2. TTS 用在线 edge-tts，配离线兜底 + 同文缓存

- **换来**：音色远好于系统 TTS（系统那个一听就是导航音）；免费。
- **代价**：依赖微软服务器，国内实测 6 句挂 1 句。所以做了三层：重试 3 次 → Windows SAPI 兜底 → 同文本复用已生成音频。

### 3. 音色靠"抬音高"凑童声

- **换来**：一个参数让声音从"成年女声"变成接近 8–10 岁。
- **代价**：微软中文音色里没有童声，抬的是基频（实测中位数 283Hz → 333Hz），不是真童声；抬太多会发假。兜底用的英文男声已被代码显式拒绝（宁可没声也不出戏）。

### 4. 形象：2D 立绘换图 + 张嘴图交替 = 伪口型；3D 评估后关掉

- **换来**：零依赖、零构建、断网可用；7 种情绪 × (正常/张嘴) = 14 张图就够，缺的图会安全回落。
- **代价**：口型只有"张/闭"两态，不是真视素对齐；表情切换有整图跳变的痕迹（用淡入 + 柔光遮）。**3D 那条**（TalkingHead + `xiaoyu.glb`）实测只剩头部晃动、嘴不动——模型缺 Oculus Visemes / ARKit 口型通道，喂数据也不会动，因此**默认关闭**，只在显式加 `?avatar3d=1` 时才加载。

### 5. 演示兜底：预置缓存优先，固定模板垫底

- **换来**：断网 / 模型挂掉时，9 句演示台词仍返回**真实回复 + 已合成音频**，听不出差别，命中率 44/44 变体测试全过。
- **代价**：只认脚本里那几句；临时改词会掉到最机械的固定模板（"我在听。你接着说。"）。所以演示必须照 `docs/演示脚本.txt` 念。

### 6. 记忆只放内存，不落库

- **换来**：三天内不需要数据库，零迁移成本、零隐私存档风险；重启即清空，符合"陪伴但不留痕"的定位。
- **代价**：**关掉窗口记忆就没了**，跨会话的"上次那件事"不存在；多轮上限 8 轮 + 摘要，再长会丢细节。

## 四、成本与依赖

| 项 | 用量 | 说明 |
|---|---|---|
| DeepSeek | 约 1 次调用/轮（情绪 + 回复合并在一次里） | 演示 9 句约 0.02 元 |
| edge-tts | 免费，按句合成 | 预演时提前生成，现场直接命中缓存 |
| 生图（Q 版小人） | 十几张、每次几分钱 | 只在做素材时用，演示不花钱 |
| 运行环境 | Python 3.10 + 浏览器 | 无 GPU 也能跑；ASR 用 CPU |

**已知局限（如实记录）**：情绪识别准确率 93%（30 条里错 2 条，都是弱情绪的边界样本）；伪口型不是真视素；
兜底模式只认脚本台词；本机依赖分布在 `site-packages` 与 `..\.pylibs` 两处，换机器要按 README 重新装。

## 五、如果要继续做（下一版优先级）

1. **换一个带口型通道的 3D 模型**（Ready Player Me 导出时勾 `morphTargets=ARKit,Oculus Visemes`）——硬件已经能吃下，是"最后 10% 观感"最划算的一步。
2. **情绪识别加上下文**：目前只看当句，孤立弱情绪会判错（实测"上次说的那个面试"被判成 sad）。
3. **记忆落库 + 用户可删**：跨会话记住才谈得上"关系"，但必须配一个"忘掉我说过的话"的入口。
4. **真视素口型**：用逐字时间戳驱动 viseme 混合，替代"张/闭"两态。
