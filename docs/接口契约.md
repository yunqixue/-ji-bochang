# 接口契约（三层对接的唯一标准）

> 三个人并行开发的前提：**先把接口定死，再各写各的**。
> 任何一方要改这里的字段，必须先改本文件 → 提交 → 通知另外两人，不许先改代码后补文档。

状态：⬜ 草案 ／ ⬜ 已定稿（定稿日期：____，三人确认：____ ____ ____）

---

## 0. 数据流总览

```
用户输入(语音/文字/摄像头)
      │
      ▼
[感知层 perception]  ──►  PerceptionResult  ──►  [认知层 cognition]
                                                        │
                                              CognitionResponse
                                                        ▼
                                             [表现层 presentation] ──► 语音 / 表情 / 文本
```

三层之间**只通过下面这两个数据结构通信**，不直接调用对方内部函数。

---

## 1. 感知层 → 认知层：`PerceptionResult`

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `timestamp` | `float` | ✅ | Unix 秒级时间戳 |
| `text` | `str \| None` | ⬜ | ASR 识别出的文本；纯文本输入时直接填入 |
| `emotion_label` | `str` | ✅ | 情绪标签，取值见 §3 |
| `emotion_score` | `float` | ✅ | 0.0–1.0 置信度 |
| `valence` | `float` | ✅ | 效价 −1.0 ~ 1.0（负→正） |
| `arousal` | `float` | ✅ | 唤醒度 0.0 ~ 1.0（平静→激动） |
| `modality` | `str` | ✅ | 来源：`audio` / `text` / `face` / `multimodal` |
| `raw` | `dict` | ⬜ | 原始分模态结果，调试用，认知层不应依赖 |

```json
{
  "timestamp": 1760000000.0,
  "text": "今天面试又没过……",
  "emotion_label": "sad",
  "emotion_score": 0.82,
  "valence": -0.61,
  "arousal": 0.35,
  "modality": "multimodal",
  "raw": {}
}
```

---

## 2. 认知层 → 表现层：`CognitionResponse`

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `reply_text` | `str` | ✅ | 要说出/显示的文字 |
| `target_emotion` | `str` | ✅ | 智能体此刻应表现的情绪（驱动表情） |
| `intensity` | `float` | ✅ | 0.0–1.0 表现强度 |
| `speech_rate` | `float` | ⬜ | 0.5–2.0 语速倍率，默认 1.0 |
| `pitch_shift` | `float` | ⬜ | 音高偏移（半音），默认 0 |
| `gesture` | `str \| None` | ⬜ | 动作提示，如 `nod` / `tilt_head` / `none` |
| `memory_used` | `list[str]` | ⬜ | 本次引用到的记忆条目 id，便于追溯 |
| `debug` | `dict` | ⬜ | 策略名、prompt 版本等，不进正式链路 |

```json
{
  "reply_text": "听起来挺难受的，愿意跟我说说是哪一轮卡住了吗？",
  "target_emotion": "empathic",
  "intensity": 0.7,
  "speech_rate": 0.9,
  "pitch_shift": -1.0,
  "gesture": "nod",
  "memory_used": ["mem_20261001_01"],
  "debug": {"strategy": "comfort_probe", "prompt_version": "v3"}
}
```

## 3. 情绪标签表（三层必须用同一套）

| label | 含义 | 中文 |
|---|---|---|
| `neutral` | 中性 | 平静 |
| `happy` | 高兴 | 开心 |
| `sad` | 悲伤 | 难过 |
| `angry` | 愤怒 | 生气 |
| `anxious` | 焦虑 | 紧张/担心 |
| `surprised` | 惊讶 | 意外 |
| `empathic` | 共情（仅表现层用） | 关切 |

> 新增标签 → 先在本表加，再同步三层的映射代码。

---

## 4. 约定

- **单位统一**：时间戳用 Unix 秒（float），音频 16kHz 单声道，图像 RGB
- **失败要显式**：任一层出错返回 `None` + 错误原因，不要返回假的默认值让下游猜
- **mock 先行**：接口定稿后，每人先写一个能返回固定样例的 mock，端到端就能提前联调
- **版本号**：字段变更时在本文件顶部记一行变更日志
