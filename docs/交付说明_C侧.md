## 二、URL 参数速查

| 参数 | 作用 |
|---|---|
| `?theme=light\|ease\|sweet\|cream\|cyber\|nature\|night` | 指定主题 |
| `?bg=home\|cafe\|park\|night\|study\|scifi\|r1..r6` | 指定背景场景 |
| `?mode=call\|text` | 通话视图 / 文字视图 |
| `?clips=1` | 说话时播放情绪视频片段（嘴真实在动，但与静态图有切换感） |
| `?mouthflip=1` | 说话时在静态图/张嘴图之间快切（画面会跳，默认关） |
| `?avatar3d=1` | 启用 3D 数字人（逐字口型） |

**默认**：静态立绘不动，靠「随音量推近 + 声音波形 + 字幕逐字」体现说话。

## 三、演示当天

1. **先在演示机跑一次 `start-demo.cmd`**——第一次要下载 50MB cloudflared，别等现场
2. 服务启动后打开 `http://127.0.0.1:8000`，确认：
   - 立绘能显示、能切表情
   - 发一句话能听到语音、能看到字幕
3. 如果想看「嘴在动」，在地址后加 `?clips=1`
4. 网断了就 `?mode=text`，或按 `docs/演示当天操作.md` 的兜底走

## 四、已知限制（如实记录）

1. **「只动嘴」做不到**——张嘴图与静态立绘不是像素级对齐，整图切换会让画面跳；抠嘴部贴回去也因构图差异成了色块。要做对需要人工 PS 抠图或出图时锁死构图。
2. **3D 模型长相与角色不一致**——示例模型是通用形象，只用于证明逐字口型链路可用。
3. **本机没有 ASR**（Python 3.14 装不了 faster-whisper），语音输入只能在 B 机验（ADR-003 / ADR-005）。
4. **全身体三视图带烤死的格子背景**（JPG 无 alpha），只能当参考图，不能直接当立绘。
