# 情感交互智能体 Agent 开发

三人团队协作项目。代码、文档、决策记录统一在本仓库，数据集走共享云盘。

## 快速开始

1. 新电脑第一次配置 → 看 [`docs/三人上手清单.md`](docs/三人上手清单.md)
2. 每天开工 → 先看 [`docs/团队任务板.md`](docs/团队任务板.md)
3. 动代码前 → 读 [`AGENTS.md`](AGENTS.md)（团队约定，DSH 会自动加载）
4. 三层之间怎么对接 → 看 [`docs/接口契约.md`](docs/接口契约.md)

## 协作模型

```
成员A 电脑 ─┐
成员B 电脑 ─┼─ 各自本地 DSH 实例 ──► 同一个 Git 仓库 ──► 同一份「团队大脑」
成员C 电脑 ─┘                          (代码/文档/任务板)      (AGENTS.md)
```

每个人的 AI 助手互相不认识，但读同一份 `AGENTS.md` + 任务板，所以对项目的理解是一致的。
改完东西 push，别人 pull 之后 AI 就知道进展 —— 这就是「数据共享」的落地方式。

## 目录

| 目录 | 用途 | 是否进仓库 |
|---|---|---|
| `src/` | 全部源码 | ✅ |
| `docs/` | 任务板、接口契约、决策记录 | ✅ |
| `assets/` | 提示词、评测样本、小素材 | ✅（单文件 < 5MB） |
| `experiments/` | 实验脚本与结果 | ✅（结果只留摘要） |
| `data/` | 数据集、模型权重、录屏 | ❌ 只提交 `MANIFEST.md` |
