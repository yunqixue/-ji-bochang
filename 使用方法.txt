====================================================
  情感交互智能体Agent开发  ——  怎么用
====================================================

【第一次，只做一次】

1) 双击本文件夹里的  push.cmd

2) 弹出登录框，填：
      用户名 = QLZ147258
      密码   = 你的 Gitee 私人令牌

   令牌去哪拿：
     Gitee 网页 → 右上头像 → 设置 → 左侧「安全设置」→ 私人令牌
     → 生成新令牌 → 勾选 projects → 生成 → 复制那串字符
     （只显示一次，先粘到记事本存好）

3) 看到  [OK] pushed  就是成功了。

4) 去 Gitee 网页刷新你的仓库，能看到这些文件 → 彻底成功。

5) 邀请队友：
   Gitee 仓库页 → 管理 → 仓库成员管理 → 邀请用户
   搜他们的 Gitee 用户名，角色选「开发者」，发邀请。


----------------------------------------------------

【以后每天就两件事】

   开工 —— 双击  pull.cmd     （拉队友的最新代码）
   干活 —— 在 DSH 里跟 AI 说你要做什么
   收工 —— 双击  push.cmd     （把你的改动传上去）

   就这两个按钮。不用记命令，不用 cd。


----------------------------------------------------

【两个队友要做的事】

1) 照  docs\三人上手清单.md  装好 Git、Node、DSH

2) 找地方打开命令行，执行两行：

      git clone https://gitee.com/QLZ147258/ji-bochang.git
      cd ji-bochang
      git config --global user.name "他们的真名"
      git config --global user.email "他们的邮箱"

3) 之后他们也是：开工双击 pull.cmd，收工双击 push.cmd


----------------------------------------------------

【出错了怎么办】

窗口里出现红字 [FAIL]，直接把窗口截图发我，我来判断。
不要自己改代码或删 .git 文件夹。
