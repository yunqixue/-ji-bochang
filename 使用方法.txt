====================================================
 情感交互智能体Agent开发 —— 三个人怎么一起干活
====================================================

【只需要记住 3 件事】

     开工   双击 pull.cmd      （把队友的改动下载下来）
     干活   在 DSH 里跟 AI 说要做什么，它自己改文件
     收工   双击 push.cmd      （把自己的改动传上去）

以后每天就这样，不用记命令。
第一次要安装配置，看下面的第一篇（队长）和第二篇（队友），只做一次。

【为什么这样三个人就能一起干活】

云端（Gitee）存一份总账。三个人电脑上各有一份完整副本。
   pull = 下载，拿别人的改动
   push = 上传，把自己的改动传出去

不是共用一个网页，也不是共用一个共享文件夹。
改的是自己电脑上的文件，push 之后就变成了大家的。


====================================================
 第一篇：队长第一次要做的（3 步，只做一次）
====================================================

第 1 步  双击 push.cmd 把东西上传
         弹框填：用户名 = QLZ147258
                 密码   = 你的私人令牌（不是登录密码）
         看到【成功】才算完成。

         私人令牌怎么拿：
           Gitee 网页 → 右上角头像 → 设置 → 左侧「安全设置」
           → 私人令牌 → 生成新令牌 → 权限勾 projects
           → 生成 → 复制那串字符（只显示一次，先存记事本）

第 2 步  把队友加进来（在 Gitee 网页上点）
         打开仓库 → 管理 → 仓库成员管理 → 邀请用户
         输入队友的 Gitee 用户名 → 角色选「开发者」→ 发送
         队友要去自己 Gitee 的消息里点【接受】，才算加进来。

第 3 步  把「第二篇」发给两个队友


====================================================
 第二篇：队友第一次要做的（5 步，只做一次）
====================================================

第 1 步  先加入仓库
         队长邀请你之后，去 Gitee 网站的消息里点【接受邀请】。
         不点的话，下面第 5 步会失败。

第 2 步  装 3 个软件（一路点"下一步"就行）
         Git      https://git-scm.com/download/win
         Node.js  https://nodejs.org        （选 LTS 版）
         Python   https://www.python.org/downloads/   （3.10 或更高）

         装完把窗口都关掉。这一步不装好，后面全做不了。

第 3 步  装 DSH
         按键盘上的 Win 键 → 输入 powershell → 回车
         会跳出一个黑窗口。把下面这行复制进去，回车，等它跑完：

             npm i -g @deepseek-ai/dsh

第 4 步  填你自己的 DeepSeek API Key
         打开 DSH 界面 → 设置 → 模型 → 填你自己的 Key。
         （Key 是自己花钱的，不要用别人的，也不要发群里）

第 5 步  把项目下载到自己电脑
         在黑窗口里，一行一行复制执行（第一行是切换到 D 盘）：

             cd D:\
             git clone https://gitee.com/QLZ147258/ji-bochang.git 情感交互智能体Agent开发

         然后告诉自己是谁（提交换名字用），换成你自己的名字和邮箱：

             git config --global user.name "你的真名"
             git config --global user.email "你的邮箱"

         第一次 push 的时候会弹框要账号密码：
             用户名 = 你自己的 Gitee 用户名
             密码   = 你自己的私人令牌（不是登录密码）
         令牌的拿法见第一篇第 1 步。

做完这 5 步，以后就只剩两个按钮：pull.cmd 和 push.cmd。


====================================================
 第三篇：每天怎么用（三个人完全一样）
====================================================

     开工   双击 pull.cmd
     干活   在 DSH 里让 AI 帮你改文件（它直接改你电脑上的）
     收工   双击 push.cmd

两个窗口都不需要你输入任何命令。
跑完会自己停住，最后两行告诉你成功还是失败，按任意键关掉。

★ 唯一要记住的规矩：**每天开工先 pull。**
  不 pull 就闷头改，容易和队友撞车，处理起来很麻烦。

★ push 提示「别人先上传了」→ 先双击 pull.cmd，再双击 push.cmd。

====================================================
 第五篇：报错了怎么办
====================================================

窗口里出现【失败】或【未知问题】，**把整个窗口截图发群里**，别自己折腾。

详细排查手册在：docs\疑难排查.md

最常见的三个原因（先自查）：
   1. 密码填错 → 要填「私人令牌」，不是登录密码
   2. 没被加进仓库 → 让队长邀请你，你还要点接受
   3. 没设名字邮箱 → 见第二篇第 5 步最后两条命令

★ 千万不要删 .git 文件夹，删了同步关系全断，只能重新下载。
