====================================================
 情感交互智能体Agent开发 —— 三个人怎么协作
====================================================

【先搞懂这个模式，后面就简单了】

云端仓库（Gitee）里存一份总账。
你、队友A、队友B 各自电脑上都有**一份完整副本**，靠两个按钮和云端同步：

     下载（拿到别人的改动）= 双击 pull.cmd
     上传（传出自己的改动）= 双击 push.cmd

★ 不是共用一个网页，也不是共用一个共享文件夹，
  而是「各自一份 + 定时同步」。改自己电脑上的文件，再 push 上去。


====================================================
 第一篇：队长（QLZ147258）—— 现在先做这 3 步
====================================================

第 1 步：把仓库推上去（只需做一次）
   双击 push.cmd
   弹框填： 用户名 = QLZ147258
            密码   = 你的 Gitee 私人令牌（不是登录密码）
   看到 [OK] pushed 才算成功。

   ★ 没做这一步，队友什么也拿不到。

第 2 步：邀请队友（在网页上做）
   Gitee → 打开仓库 → 管理 → 仓库成员管理 → 邀请用户
   输入队友的 Gitee 用户名 → 角色选「开发者」→ 发送邀请
   队友要去自己 Gitee 的消息里点「接受」，才算加入。

第 3 步：把下面「第二篇」的内容发给队友


====================================================
 第二篇：队友 —— 新电脑只需要做一次
====================================================

前提：已经被队长加进仓库（Gitee 消息里点了接受）。
      没加进去的话，私有仓库是拉不到的，会报 Repository not found。

1) 装工具（装完关掉终端重开）
   Git      https://git-scm.com/download/win  一路默认下一步
   Node.js  https://nodejs.org  装 LTS 版
   Python   3.10 或更高

   验证：在命令行敲  git --version  能出版本号就行

2) 装 DSH
   npm i -g @deepseek-ai/dsh

3) 配置自己的提交身份（一次就够）
   git config --global user.name "你的真名"
   git config --global user.email "你的邮箱"

   ★ 不设这个，第一次上传会报 Author identity unknown

4) 把仓库拉到自己电脑
   cd D:\
   git clone https://gitee.com/QLZ147258/ji-bochang.git 情感交互智能体Agent开发

   ★ 建议就放在 D:\ 下面，三人路径一致，文档里的路径才通用

5) 第一次上传时会弹框要凭据，填**自己的**账号：
   用户名 = 你自己的 Gitee 用户名
   密码   = 你自己的 Gitee 私人令牌（不是登录密码）
   令牌在：Gitee 头像 → 设置 → 安全设置 → 私人令牌
           → 生成新令牌 → 权限勾 projects → 生成 → 复制（只显示一次）

以后的日常操作见第三篇。


====================================================
 第三篇：每天怎么用（三个人完全一样）
====================================================

   开工前    双击 pull.cmd    ← 先把队友的改动拿下来
   干活      在 DSH 里让 AI 帮你改文件（直接改自己电脑上的）
   收工      双击 push.cmd    ← 把改动传上去
             会问你一句说明，填类似： feat: 加了语音识别

★ 铁律：**改文件之前先 pull**。
  不 pull 就闷头改，很容易和别人撞车，处理冲突很麻烦。


====================================================
 第四篇：谁改哪里（避免互相覆盖）
====================================================

   队友A   →  docs/ 、assets/prompts/ 、assets/images/
   队友B   →  src/perception/ 、src/cognition/
   队友C   →  src/presentation/ 、src/shared/

   共用文件（AGENTS.md、docs/团队任务板.md、docs/接口契约.md）
   改之前先在群里说一声，别两个人同时改。


====================================================
 第五篇：出问题对照表
====================================================

   Authentication failed      → 密码填错了，要填私人令牌，不是登录密码
   Repository not found       → 没被加进仓库，或 Gitee 用户名写错
   Author identity unknown    → 没做第二篇第 3 步
   conflict / 冲突提示        → 别自己乱改乱删，截图发群里
   弹窗一直不出来             → 把窗口关掉重新双击，或重启电脑再试
   [FAIL] 后面一段英文        → 把整个窗口截图发群里，别自己想办法

★ 千万不要手动删 .git 文件夹，删了等于把同步关系全断了。
