# 形象生成提示词（保证 7 张图是"同一个人"）

> 负责人：**A** ｜ 前端接入：**C**
> 目标：7 张表情图，**长相、发型、衣服、背景完全一致**，只有表情不同。
> 最大的坑：每次生图人物都不一样 → 换表情时像换了个人。下面第 3 节的技巧是唯一可靠解法。

---

## 1. 角色设定（先由 A 定稿，之后所有图都照这个描述）

| 项 | 内容 |
|---|---|
| 风格 | 日系动画插画，干净线条，柔和上色 |
| 年龄 / 性别 | 25 岁女性 |
| 发型 | 齐肩黑发，发尾微卷，右侧一缕别在耳后 |
| 眼睛 | 温暖的浅褐色 |
| 服装 | 米色宽松针织毛衣（**固定，换衣服就完全不同人**） |
| 配饰 | 左耳一只小银耳钉 |
| 背景 | 纯色浅米色 `#F5F0E8`（固定，方便排版和抠图） |
| 构图 | 上半身，正面略偏 3/4，视线看向观众 |
| 尺寸 | 768 × 1024 |

---

## 2. 统一前缀（每一张都要带，一个字都别改）

```
anime style illustration, clean lineart, soft pastel colors,
single female character, 25 years old, upper body portrait, facing viewer,
shoulder-length black hair with slightly wavy ends, one strand tucked behind right ear,
warm light-brown eyes, small silver stud earring on left ear,
wearing an oversized beige knit sweater,
plain solid light beige background #F5F0E8, soft lighting, high quality character design,
```

## 3. 七个表情后缀（拼在前缀后面）

| 文件名 | 情绪 | 后缀 |
|---|---|---|
| `expr_neutral.webp` | 平静 | `calm gentle expression, closed mouth, soft gaze at viewer` |
| `expr_happy.webp` | 开心 | `soft warm smile, eyes slightly curved, cheerful mood` |
| `expr_sad.webp` | 难过 | `downcast eyes, slight frown, mouth corners turned down, melancholy` |
| `expr_anxious.webp` | 焦虑 | `slightly raised inner eyebrows, worried eyes, lips gently pressed` |
| `expr_angry.webp` | 生气 | `furrowed brows, pressed lips, firm steady gaze, restrained anger` |
| `expr_surprised.webp` | 惊讶 | `raised eyebrows, mouth slightly open, wide eyes` |
| `expr_empathic.webp` | 共情 | `gentle concerned expression, soft warm eyes, subtle reassuring smile` |

> `empathic` 是智能体回复时的表情（对应契约里的 `target_emotion`），其余 6 个对应用户情绪。

---

## 4. 关键技巧：怎么让 7 张是同一个人

1. **先生成 `neutral`**，反复抽到一张满意的（这一步可以抽 10 次）
2. **记下 seed**（即梦/豆包都支持固定种子），或把这张图下载下来
3. 后续 6 张**必须用「参考图 / 角色一致性 / 图生图」**：把 neutral 那张作为角色参考，**只改表情后缀**
4. 尺寸、背景色、服装词一字不改
5. 一次只生一张，生完立刻检查"是不是同一张脸"

**不要**只靠文字描述去生 7 张 —— 那样 100% 会变成 7 个人。

---

## 5. 导出规范

- 格式 **webp**，单张 < 300KB（仓库单文件上限 5MB，但图大了页面加载慢）
- 放到 `assets/images/`，文件名严格用上表的名字
- 同一批次的图，**背景色必须完全一致**（否则切换时会闪）

## 6. 时间不够时的降级方案

| 张数 | 效果 |
|---|---|
| 7 张全有 | 完整 |
| **只做 3 张**（`neutral` / `sad` / `happy`） | **够演示**，其余情绪复用 neutral |
| 只有 1 张 | 形象退化成"静态头像"，靠 CSS 微动效撑 |

**D1 晚上必须先有 `neutral` 一张**，让 C 能开始接前端。别等 7 张齐了才给。
