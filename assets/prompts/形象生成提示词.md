## 1. 统一前缀（每张都要带，一个字都别改）

```
same girl as the reference image, 9 years old, long fine blonde hair, light gray-blue eyes,
wearing the same light gray hoodie, sitting in the same dark bedroom at night,
warm lamp and laptop screen glow, same camera distance, upper body portrait facing viewer,
semi-realistic 3D render, vertical composition 3:4,
no text, no watermark, no logo, no signature,
```

## 2. 六个表情后缀（拼在前缀后面，一次只改这一句）

| 文件名 | 情绪 | 后缀 |
|---|---|---|
| `expr_happy.webp` | 开心 | `big genuine smile showing teeth, eyes curved, delighted mood` |
| `expr_sad.webp` | 难过 | `downcast eyes, slight frown, mouth corners down, eyes glistening` |
| `expr_anxious.webp` | 焦虑 | `inner eyebrows raised, worried eyes, lips pressed together` |
| `expr_angry.webp` | 生气 | `furrowed brows, pressed lips, firm steady gaze, restrained anger` |
| `expr_surprised.webp` | 惊讶 | `raised eyebrows, mouth slightly open, wide eyes` |
| `expr_empathic.webp` | 共情 | `gentle concerned expression, soft warm eyes, small reassuring smile` |

> `empathic` 是智能体回复时的表情（对应契约里的 `target_emotion`），其余对应**用户情绪**
> （用户难过 → 她换上 `sad`；用户开心 → 她换上 `happy`）。别搞反。

## 3. 三条硬要求（第一版踩过的坑）

1. **竖构图 3:4**。豆包默认吐 16:9 横图，横图裁进页面竖框只剩 38–42% 宽度，人物会变小或被切。
   提示词里写死 `vertical composition 3:4`；出图后先看比例。
2. **不要全身、不要远景**。要上半身，头部占画面高度 1/3 左右——和其他张的景别一致，
   否则切表情时人物忽大忽小。
3. **负面词必须带**：`no text, no watermark, no logo, no signature`。
   第一版有 3 张带「豆包 AI 生成」水印或 `PRAGMATA / DIANA` 字样，现场大屏一放大就看得见。
   现在统一在入图时裁掉底部 9%（`prep-images.cmd --trim-bottom 0.09`），不用指望生图工具听话。
4. **导出后立刻改名**。豆包导出的文件名会重名（连着两次导出都叫「变清晰 (16)」），
   后下载的直接把前一张覆盖掉 —— 已经发生过一次。下载完马上改成 `neutral.png` / `sad.png` 这种表情名。

## 4. 一次生成一张，生成即检查

1. 上传底图 → 只改表情后缀 → 生成
2. 立刻问三件事：① 同一张脸吗 ② 卫衣/房间/光线变没变 ③ 人物在框里的大小一样吗
3. 有一项不对就重抽，**不要凑合**（凑合的代价是演示时像换了个孩子）
4. 抽到满意的，命名成表情名丢进 `data/raw_images/`（`happy.png` / `sad.jpg` …）

## 5. 一键规整 + 审查（不用手动改尺寸/格式）

```
① 原图丢进 data/raw_images/，文件名就是表情名
② 双击 experiments/prep-images.cmd         → 缩 768×1024、转 webp、压到 <300KB
③ node experiments/imgtool/review-sheet.js → 出拼图，看"是不是同一个人"
   （拼图在 experiments/preview/contact_sheet.webp）
```

脚本会拦三件事：文件名写错（前端永远找不到图）、单张 >300KB、同名重复。
详细说明见 `experiments/imgtool/README.md`。
